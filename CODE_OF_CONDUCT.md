# Code of conduct

Short version: be useful, be honest, assume the other person is doing their
best with the time they have.

## Expected

* Keep discussion on the work: the code, the bug, the trade-off.
* Say what you tested and what you did not. Uncertainty stated plainly is worth
  more than confidence invented.
* Accept that "no, not in this project" is a complete answer when it comes with
  a reason. The scope is deliberately narrow.

## Not accepted

* Personal attacks, harassment, or dragging someone's identity into a technical
  discussion.
* Posting other people's data — a guest's photo, an event's share link, a
  device key — in an issue or a pull request.
* Bulk automated pull requests that nobody reviewed before sending. An agent may
  contribute; an unattended pipeline spraying changes may not.

## Enforcement

Report a problem privately to the maintainer through GitHub
(<https://github.com/tillheidrich>), or in an issue if it may be public. The maintainer decides, says why,
and may edit, close or block. There is no committee; this is a small project and
pretending otherwise would not help anyone.
