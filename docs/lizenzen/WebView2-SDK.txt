Microsoft Edge WebView2 SDK (NuGet package Microsoft.Web.WebView2)

Applies to: Microsoft.Web.WebView2.Core.dll, Microsoft.Web.WebView2.WinForms.dll
and WebView2Loader.dll as shipped inside the pywebview wheel (webview/lib/) and
packed into PhotoboxBooth.exe. Licence text taken verbatim from
https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4314.35/License
(retrieved 15.11.2026). The pywebview wheel may carry an older SDK version;
the licence text of the SDK has been this BSD-style text for the versions
checked - compare it with the NuGet page of the version pywebview names
before a release.

The Microsoft Edge WebView2 Runtime (the browser engine itself) is NOT part of
this program. It ships with Windows 11 and is otherwise installed from
Microsoft under Microsoft's own licence terms.
