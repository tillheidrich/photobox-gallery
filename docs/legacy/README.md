# Legacy documentation (German, partly outdated)

These files describe the gallery as it was before the booth and the sync
package existed. They are kept because they explain decisions that are still
visible in the code — the database layout, the routes, the old Windows client.

They are **not** authoritative. Where they disagree with the code, the code
wins; the current documentation is [`AGENTS.md`](../../AGENTS.md), the files
in [`docs/`](../) and [`business_logic/`](../../business_logic/).

Do not "fix" these files. If something here is wrong, it is history.
