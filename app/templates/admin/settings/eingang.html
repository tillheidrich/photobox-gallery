Dienste

Beide sind aus, bis du sie einschaltest. Ein offener Port ist eine Entscheidung, keine Voreinstellung — und er muss zusätzlich am Server freigegeben werden (in Coolify unter „Ports", bei Docker -p, dazu die Firewall).

Der empfohlene Weg: verschlüsselt, ein Port, keine Zertifikatsfragen.

FTP braucht für jede Datei einen zweiten Port. Dieser Bereich muss ebenfalls freigegeben sein, sonst bleibt die Verbindung beim Übertragen stehen.

Ein Kennwort, das über ein fremdes Veranstaltungs-WLAN im Klartext geht, ist ein verschenktes Kennwort. Klartext nur, wenn das Programm nichts anderes kann und der Weg im eigenen Netz bleibt.

Leer: Die Galerie erzeugt eines selbst. Das verschlüsselt genauso gut, weist aber nichts nach — der Client kann nicht prüfen, mit wem er spricht. Für einen Box-Rechner im selben Netz reicht das; für einen Upload über das Internet gehört ein echtes hierher.

Was ein Konto darf

Hochladen, Ordner anlegen, eigene Zwischendateien umbenennen und aufräumen. Nicht: aus dem eigenen Ordner heraus, fremde Events sehen, oder etwas aus der Galerie löschen. Gelöscht wird in der Galerie.

Eine hochgeladene Datei geht denselben Weg wie jeder andere Upload — Vorschaubilder, Prüfsumme, Freigabe. Steht das Event auf Moderation, wartet auch eine FTP-Aufnahme auf deine Freigabe. Die Art wird am Dateinamen erkannt, nach denselben Regeln wie im Sync-Programm: *print* ist ein Druck, *original* ein Original, GIF ist ein GIF, MP4/MOV ein Video.
